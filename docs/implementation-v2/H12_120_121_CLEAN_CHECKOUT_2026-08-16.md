## A real ordering constraint this surfaced

The first clean-checkout attempt failed at `check-format.sh` with
`sh: 1: prettier: not found`, exit 127, after 7 s. `check-all.sh` reaches the
webapp format check *before* `check-webapp.sh` performs `npm ci`, so the gate
cannot bootstrap its own frontend dependencies from a genuinely clean tree.

That is less a defect in the gate than an undocumented precondition: the
documented setup in `docs/DEVELOPMENT.md` installs dependencies first, and doing
so makes the gate pass. It is recorded because a clean checkout is exactly where
it bites, and a future release run will hit it again.
