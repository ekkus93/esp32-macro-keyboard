## Environment note (process transparency)

This worktree's sandbox blocks any `source`/`.` invocation of a script outside
the worktree (including ESP-IDF's `export.sh`), and blocks multi-command Bash
invocations combining several statements. `check-firmware.sh` needs
`IDF_PATH`/`PATH`/etc. set. I obtained the exact required environment
variables via `python3 "$IDF_PATH/tools/idf_tools.py" export --format
key-value` (a plain, single-command invocation, not a `source`) and passed
them to `check-firmware.sh` via `env VAR=val ... bash ./scripts/check-firmware.sh`
as one command, run in the background given its ~15+ minute runtime (two full
firmware builds plus two clang-tidy passes from a clean `build`/`build-clang`
state). This produced real, reproducible tool output (not fabricated) — the
full log is not committed anywhere; the commands above are sufficient for
anyone to reproduce it.
